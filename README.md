# Lista de Tarefas - Flet
Aplicativo de lista de tarefas desenvolvido em Python utilizando Flet.

## Funcionalidades
- Criar tarefas
- Visualizar tarefas
- Editar tarefas
- Excluir tarefas
- Marcar tarefas como concluídas
- Definir prioridade
- Salvar tarefas em arquivo JSON

## Tecnologias
- Python
- Flet
- JSON

## CRUD
Create: adicionar tarefas.
Read: visualizar tarefas.
Update: editar tarefas e marcar como concluídas.
Delete: excluir tarefas.

## Como executar
Instale o Flet:
pip install flet
Depois execute:
python main.py
